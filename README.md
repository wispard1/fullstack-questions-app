# Fullstack Questions App

Веб-приложение для работы с базой вопросов: пагинация, фильтрация и просмотр деталей вопроса.

## Стек
- TypeScript
- React
- Redux Toolkit + RTK Query
- React Router DOM
- Feature Sliced Design (FSD)

## Запуск
npm install
npm run dev

## Деплой
